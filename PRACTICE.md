## Reattempting a problem

1. Open the problem on NeetCode and try it from a blank editor before reading the
   saved solution.
2. State the invariant or key idea, then explain the time and space complexity.
3. Check the input constraints and test the relevant edge cases, such as repeated
   values, a single element, and empty input when allowed.
4. Compare with the saved submissions after the attempt and note the step that
   needed a hint.

Submissions use the platform's problem-specific method signatures and test harness;
they are not necessarily standalone command-line programs. A synced file by itself
does not establish that it was accepted, since sync behavior depends on the account's
settings.

See [README.md](README.md) for GitHub Sync settings and the generated repository
structure. This index is maintained separately from that generated README.
